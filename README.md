# QPICK — интернет-магазин аудио-аксессуаров

Тестовое задание на позицию Frontend-разработчика.

## Стек
- React + TypeScript
- React Router v6
- Vite
- Context API + SessionStorage
- CSS (адаптивная вёрстка)

## Функционал
- Каталог: секции «Наушники» и «Беспроводные наушники»
- Корзина: изменение количества, удаление товара, пересчёт суммы
- Счётчик товаров в шапке
- Модальное окно с подробной информацией о товаре
- Модальное окно оформления заказа
- Хранение корзины в SessionStorage
- Адаптивность под мобильные устройства

## Запуск
```bash
npm install
npm run dev
